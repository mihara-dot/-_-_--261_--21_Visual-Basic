# Роль
Ты работаешь как ИИ-агент внутри учебного проекта. Собери цельную одностраничную рекламную веб-страницу из материалов студента. Сохраняй авторские решения и не подменяй их современным шаблоном.

# Перед сборкой
1. Прочитай README.md.
2. Полностью прочитай research.md, era.md, concept.md и sources.md.
3. Найди все Markdown-файлы в blocks/ и прочитай их по порядку.
4. Просмотри assets/.
5. Кратко сформулируй, что понял об объекте, эпохе, концепции и структуре.
6. После этого собери index.html.

# Источники истины
- research.md — исторические факты;
- era.md — эпоха и визуальная среда;
- concept.md — рекламная идея;
- blocks/*.md — набор и порядок секций;
- sources.md — подтверждения;
- assets/ — локальные материалы.

Не меняй Markdown-файлы без отдельной команды студента.

# Главная задача
Создай готовый index.html — рекламную страницу вымышленных курсов Visual Basic 6.0, правдоподобную для 1997–1999 годов.

# Ограничения
- Не придумывай исторические даты, цитаты и цифры.
- Не добавляй современные шаблонные секции.
- Не используй внешние библиотеки для просмотра.
- Все локальные изображения подключай относительными путями.
- Сохраняй порядок блоков.
- Сохраняй смысл фактов из research.md.
- Используй плотность, рамки, кнопки, панели и системную эстетику Windows 95/98.

# Самопроверка
Проверь, что каждый файл blocks/*.md отражён в index.html, все изображения открываются, текст читается, а страница запускается двойным щелчком.
