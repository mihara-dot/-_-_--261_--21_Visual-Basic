## Как открыть

Открыть `index.html` в браузере двойным щелчком.

## Коротко о проекте

Проект показывает Visual Basic в его поздней Windows 9x эпохе, когда Visual Basic 5.0 и 6.0 продвигались как инструменты быстрой разработки приложений. Рекламная страница стилизована под компьютерную культуру конца 1990-х: окна, панели, кнопки, пиксельные акценты и плотная компоновка.
