# Исследование Visual Basic

## Коротко
Visual Basic — язык программирования и среда разработки Microsoft, впервые представленные в 1991 году. Его ключевая особенность для выбранной эпохи — ориентация на быстрое создание приложений для Windows с графическим интерфейсом.

## Происхождение
20 мая 1991 года Microsoft объявила Visual BASIC for Windows на Windows World 1991 в Атланте. В дальнейшем появились Visual Basic 2.0, 3.0, 4.0, 5.0 и 6.0.

## Исходная проблема
Разработчикам Windows-приложений требовался способ быстрее создавать пользовательские интерфейсы и прикладные программы. Visual Basic связывал визуальное проектирование форм и элементов управления с написанием кода.

## Пользователи и области применения
Visual Basic применялся для настольных Windows-приложений, бизнес-программ, клиент-серверных решений, работы с данными и, в версиях 5.0/6.0, для ряда интернет- и компонентных сценариев.

## Ключевые вехи
1. 1991 — объявлен Visual BASIC for Windows.
2. 1992 — Visual Basic 2.0.
3. 1993 — Visual Basic 3.0.
4. 1995 — Visual Basic 4.0, поддерживающий Windows 95.
5. 1997 — Visual Basic 5.0; Microsoft связывала его с RAD, повышением производительности, базами данных и ActiveX.
6. 1998 — Visual Basic 6.0 вошёл в Visual Studio 6.0; добавлены возможности работы с данными, Web и корпоративными приложениями.

## Важные платформы, продукты и проекты
- Windows 3.x и Windows 95/98.
- Visual Studio 97.
- Visual Studio 6.0.
- ActiveX.
- ODBC/OLE DB и работа с базами данных.
- Microsoft SQL Server и Oracle в сценариях работы с данными.

## Почему объект был ценен в выбранную эпоху
В 1997–1999 годах Visual Basic предлагался Microsoft как средство быстрой разработки Windows-приложений. В официальном сообщении о VB 5.0 Microsoft называла его RAD-инструментом и отмечала возможности native code compilation, работы с базами данных и ActiveX. В сообщении о VB 6.0 отдельно подчёркивались доступ к данным, Web-разработка, упрощённое развёртывание и корпоративные приложения.

## Факты для рекламной концепции
- Visual Basic 5.0 был представлен как RAD-инструмент.
- Microsoft сообщала о более чем 3 млн разработчиков Visual Basic в 1997 году.
- В январе 1998 года Microsoft сообщала о более чем 1 млн лицензий Visual Basic 5.0 с момента запуска.
- Visual Basic 6.0 был объявлен 15 июня 1998 года.
- Visual Studio 6.0 официально вышел 2 сентября 1998 года.
- Windows 98 стала доступна 25 июня 1998 года.
