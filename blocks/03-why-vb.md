# Зачем нужен Visual Basic
## Назначение
Показать практическую ценность языка.
## Содержание
Формы + элементы управления + код событий + работа с данными. В официальных материалах Microsoft VB5/6 описывался как RAD-инструмент.
## Связь с объектом
Это центральная идея Visual Basic.
## Связь с эпохой
Windows-приложения и бизнес-программы конца 1990-х.
## Визуальные ориентиры
Макет окна приложения с кнопками и полями.
