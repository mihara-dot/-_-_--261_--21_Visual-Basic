# Кто приходит на курс
## Назначение
Показать типичного ученика эпохи.
## Содержание
Молодой разработчик, офисный специалист или студент с Windows 95/98 и мышью хочет сделать небольшую программу для учёта клиентов, товаров или документов.
## Связь с объектом
Visual Basic применялся для прикладных и бизнес-программ.
## Связь с эпохой
Персональный компьютер становится рабочим инструментом, а Windows — привычной графической средой.
## Визуальные ориентиры
Рабочий стол, окно программы, CD-ROM.
