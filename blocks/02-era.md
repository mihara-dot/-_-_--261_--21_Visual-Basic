# 1998: год Windows-программиста
## Назначение
Объяснить выбранную историческую среду.
## Содержание
1997–1999: Visual Basic 5.0 и 6.0, Visual Studio 97/6.0, Windows 95/98. В 1998 году Windows 98 стала доступна 25 июня, Visual Basic 6.0 был представлен 15 июня, а Visual Studio 6.0 стал доступен 2 сентября.
## Связь с объектом
Показывает, почему VB6 логично рассматривать именно в этой эпохе.
## Связь с эпохой
Windows 98, CD-ROM, VGA, мышь, офисный ПК.
## Визуальные ориентиры
Плотная сетка, маленькие системные элементы.
