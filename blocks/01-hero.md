# Первый экран — Visual Basic 6.0
## Назначение
Сразу показать эпоху, объект и рекламное обещание.
## Содержание
Заголовок: «Visual Basic 6.0». Подзаголовок: «Соберите Windows-приложение, пока сосед пишет техническое задание». Кнопка: «Смотреть программу курса».
## Связь с объектом
Visual Basic 6.0 позиционировался Microsoft как инструмент быстрой разработки.
## Связь с эпохой
1998 год, Windows 98, плотная интерфейсная эстетика.
## Визуальные ориентиры
Серые панели, синие заголовки, прямоугольные кнопки, рамки Windows 95/98.
