# Ключевая эпоха

## Временной диапазон
1997–1999 годы.

## Почему выбран этот период
Период связывает Visual Basic 5.0, Visual Studio 97, Visual Basic 6.0 и Visual Studio 6.0 с массовой Windows-средой. В 1998 году одновременно присутствуют Windows 98, Visual Basic 6.0 и Visual Studio 6.0, что даёт особенно выразительную технологическую среду.

## Технологическая среда
- Windows 95/98 и Windows NT 4.0.
- Персональные компьютеры с процессорами семейства 486/Pentium.
- VGA/Super VGA-мониторы.
- CD-ROM.
- Клавиатура и мышь.
- Локальные программы, офисные приложения и ранние веб-технологии.
- Для Visual Basic 6.0 Professional: 486DX/66 или выше, Windows 95+ либо Windows NT 4.0 SP3+, 16 МБ RAM для Windows 95 (32 МБ рекомендовано), CD-ROM и VGA/Super VGA.

## Визуальный язык
- Серые панели и системные элементы Windows.
- Прямоугольные кнопки и поля.
- Тонкие рамки и выпуклые/вдавленные элементы.
- Плотное размещение информации.
- Системные шрифты без современного минимализма.
- Маленькие пиктограммы и меню.
- Компьютерная реклама с акцентом на производительность, совместимость и «будущее».

## Рекламный язык
Обещание практической пользы: «быстрее создать приложение», «работать с данными», «сделать Windows-программу», «готовый инструмент для разработчика».

## Культурный фон
Windows 95/98, CD-ROM, компьютерные журналы, первые массовые веб-сервисы, офисные ПК и рост интереса к Internet.

## Границы стилизации
Не использовать современный лендинг с огромными карточками, стеклянными градиентами, чрезмерными скруглениями, неоновым cyberpunk-стилем и большим количеством пустого пространства.
